Definition (technical):
	Machine Learning is the study of algorithms that improve their performance on a task through experience (data).

\begin{abstract}
This paper examines recent advances in intelligent surveillance and introduces a hybrid AI-based system for border security. The system integrates PIR motion sensing, webcam-based image capture, YOLOv8 object detection, and face recognition. Unlike traditional CCTV systems, the proposed model is event-driven, activating only upon motion detection. This reduces computational cost, power usage, and improves reliability in remote environments. The system enhances situational awareness, reduces false alarms, and enables real-time alerts.
\end{abstract}

\section{Introduction}
Modern surveillance systems must go beyond continuous monitoring to intelligent decision-making. Traditional methods such as CCTV and manual observation suffer from fatigue, data overload, and inefficiency.

\subsection{Need for Reliable Surveillance}
Security systems must operate reliably in high-risk environments like borders. Human monitoring leads to fatigue and missed detections.

\subsection{Challenges in Existing Systems}
\begin{itemize}
\item High false alarms due to environmental factors
\item Poor detection in low-light conditions
\item Heavy reliance on human monitoring
\item Network instability issues
\end{itemize}

\subsection{Role of AI}
AI enables systems to distinguish between meaningful and irrelevant events, reducing unnecessary alerts.

\section{Problem Statement}
Existing surveillance systems either rely on continuous video monitoring or simple motion detection. These approaches lead to:
\begin{itemize}
\item High power consumption
\item False alarms
\item Reduced reliability
\end{itemize}

There is a need for a hybrid system that combines motion detection with intelligent verification.

\section{Objectives}
\begin{enumerate}
\item Design a PIR + AI-based surveillance system
\item Implement trigger-and-verify mechanism
\item Detect human presence using AI
\item Generate real-time alerts
\item Reduce false alarms
\end{enumerate}

\section{Proposed Methodology}
\begin{enumerate}
