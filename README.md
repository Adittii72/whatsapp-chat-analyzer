# WhatsApp Chat Analyzer 📊

A simple and interactive WhatsApp Chat Analysis web application built using **Python** and **Streamlit**.

This project analyzes exported WhatsApp chats and provides meaningful insights through statistics, visualizations, and text analysis.

---

## Features 🚀

- Total messages, words, media, and links shared
- Monthly and daily timelines
- Most active users analysis
- Activity heatmaps
- Word cloud generation
- Most common words analysis
- Emoji analysis
- Interactive visualizations

---

## Tech Stack 🛠️

- Python
- Streamlit
- Pandas
- Matplotlib
- Seaborn
- WordCloud
- Emoji
- URLExtract
